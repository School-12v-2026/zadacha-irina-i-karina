# 📌 Zadacha Irina i Karina

Проектът **zadacha-irina-i-karina** е учебна задача, разработена от ученици от 12В клас към организацията **School-12v-2026**.  
Репозиторият съдържа решение на задача, реализирана на C# с помощта на .NET и Visual Studio.

---

## Описание

Този проект представлява решение на програмна задача, което демонстрира:

- Работа с езика **C#**
- Използване на .NET среда
- Структуриране на проект чрез Visual Studio Solution (.sln)
- Основни принципи на програмирането – променливи, условни конструкции, цикли и логика

Проектът може да бъде отворен, компилиран и стартиран чрез Visual Studio или .NET CLI.

## Как да стартирате проекта

Уверете се, че имате инсталирани:
- .NET SDK  
- Visual Studio (препоръчително)  
  или  
- Visual Studio Code с C# разширение  

Проверка за .NET:
dotnet --version

Стъпки за стартиране
Клонирайте репозиторият:

git clone https://github.com/School-12v-2026/zadacha-irina-i-karina.git
Отворете файла:
zadacha irina i karina.sln
в Visual Studio.
Натиснете Start (F5), за да компилирате и стартирате проекта.
